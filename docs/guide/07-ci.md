# 07 · CI / Git 集成

loom 适合在 CI 管线中做两件事：**校验 schema 完整性** 和 **防止格式漂移**。

## GitHub Actions

```yaml
# .github/workflows/schema-check.yml
name: schema-check
on: [push, pull_request]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: pnpm/action-setup@v4
        with: { version: 9 }

      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'pnpm'

      - run: pnpm install --frozen-lockfile
      - run: pnpm -r run build

      # 校验 schema 无错误
      - run: npx tsx packages/cli/src/main.ts check schema/

      # 检查格式化（退出码 1 = 有未格式化文件）
      - run: npx tsx packages/cli/src/main.ts fmt --check schema/

      # 投影 SQL，检测 golden 漂移
      - run: |
          npx tsx packages/cli/src/main.ts project sql --dialect pg schema/ > /tmp/schema.sql
          git diff --exit-code /tmp/schema.sql || \
            (echo "projected SQL drift detected; regenerate and commit" && exit 1)
```

## 检查项说明

| 命令 | 检查什么 | 失败退出码 |
|---|---|---|
| `loom check` | schema 类型引用完整、无语义错误 | 1 |
| `loom fmt --check` | 所有 YAML 文件格式化一致 | 1 |
| `loom project sql` + diff | 投影输出与提交的 golden 一致（可选） | git diff 退出码 |

## pre-commit hook

```sh
# .git/hooks/pre-commit
#!/bin/sh
npx tsx packages/cli/src/main.ts check schema/ || exit 1
npx tsx packages/cli/src/main.ts fmt --check schema/ || exit 1
```

## diff-stability 契约

loom 的投影器是**确定性**的——同样的输入产出字节级一致的输出。这意味着：

- design schema diff → 物理 SQL diff，可预测
- 重新投影 → 输出不变（除非真的有语义变更）
- 适合 GitOps：schema 变更通过 PR review，CI 自动验证

`loom fmt` 进一步保证 YAML 文件的 diff-stability——key 顺序固定，避免无关的格式变动搅乱 diff。
